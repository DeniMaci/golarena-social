# golarena-social

Public media files for GolArena's social posts. Mark's daily posting desk (a scheduled Claude routine)
pushes each post's image or film here under `<yyyy-mm-dd>/<slug>/`, and Metricool fetches it from the
GitHub Pages address `https://denimaci.github.io/golarena-social/...` when the post is scheduled.

Only finished, compliance-checked post media lives here (GolArena repo: `docs/marketing/BAN_PROOF_GATE.md`).
No code, no data, no captions, no plans. Everything here is public by design.
